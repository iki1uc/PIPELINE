# PIPELINE · Grundachse

Zweck:
PIPELINE ist die Hauptachse, aus der PIPELINE1–4 entstehen.
Sie bildet den vollständigen Durchlauf:
SCAN → OCR → NET/NC → OUTPUT/OI.

Axiome:
K(t) = 1 / (1 - t)
Φ(t) = φ∞ · K(t)
DualTransport: io = +Δx·K(t), oi = -Δx·K(t)
TRANS-WARB: Sprung 3 → CUBIT → Sprung 4 → OI

Struktur:
PIPELINE1 = SCAN
PIPELINE2 = OCR
PIPELINE3 = NET/NC
PIPELINE4 = OUTPUT/OI

Kompatibilität:
- IO / OI
- TRANS-WARB
- WARB KANAL
- Highway
- Slalom
- Axiom-Dreieck-6
- Modul-IO-8
